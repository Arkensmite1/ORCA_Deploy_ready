ABOUT THIS DOCUMENT
Purpose
This document is the complete, unabridged, end-to-end engineering and product spec-
ification for ORCA — Marine EcOsystem Reasoning with Collaborative Agents .
It is written so that it can be handed, as-is, to a human engineering team or to an
AI coding agent and used directly as the single source of truth for building the appli-
cation from an empty repository through to a fully working, edge-case-tested, demo-
ready product.
Nothing in the original specification has been shortened, summarized, or paraphrased
away . Every requirement, every agent definition, every UI mock, every state machine,
every edge case, and every red-team question from the original build prompt is pre-
served in full below , organized into 154 numbered sections plus supporting front
matter , so that no requirement is lost between planning and implementation.
How This Document Is Organized
1. Sections 1–17 define the product vision, the official problem statement, the
three-layer architecture principle, the required agents, agent contracts, orches-
tration, and the end-to-end user query pipeline.
2. Sections 18–46 define the conversational interface, response design, multi-day
trip planning, the active-trip state machine, continuous monitoring, event-driven

tem, performance, observability , and the full demo simulation timeline.
4. Sections 84–104 define the exhaustive edge-case catalogue across user , loca-
tion, weather , ocean, agent, emergency , community , privacy , network, and data
dimensions, along with the core safety principles, testing scenarios, red-team
questions, UX red-team questions, and accessibility requirements.
5. Sections 105–125 define the technology stack, repository structure, documen-
tation set, database seeding, the simulation engine, the emergency data model
and status machine, trip history , the learning loop, performance architecture,

• Treat every requirement below as mandatory unless it is explicitly described as

1. PRODUCT
ORCA
Marine EcOsystem Reasoning with Collaborative Agents
ORCA is an Agentic AI-powered marine intelligence and safety platform.
Its purpose is not merely to answer:
“Can I go fishing tomorrow?”
Its purpose is to support the user across the entire marine journey :
PLAN → DECIDE → DEPART → MONITOR → DETECT → ALERT → GUIDE →
RESPOND → RESCUE → RECOVER → RETURN
The defining product principle is:
ORCA DOES NOT STOP AT THE INITIAL RECOMMENDATION.
If ORCA says:
“Tomorrow looks safe.”
and the user goes to sea, ORCA continues monitoring relevant conditions.
If conditions change:
ORCA detects the change → verifies it → assesses risk → alerts the user →
recommends an action → continues monitoring.
11
If the user enters an emergency:
ORCA switches to Emergency Mode → provides actionable instruc-
tions → captures location → initiates available emergency communica-
tion/integration → supports rescue coordination → continues monitoring
until the situation is resolved.
This lifecycle is the most important product principle.
